# 族谱操作 & AI 智能体 · 改善计划（2026-05）

> 基于当前实现复盘。原则不变：**对话建议 / 整理执行 / 差异确认 / 可视化编辑** 四层分离。

## 现状痛点（复盘）

| 区域 | 问题 |
|------|------|
| 扫描建谱 | API 曾 15s 超时；后端未启动时错误不明确 |
| 原文 → 主谱 | 两阶段解析失败时兜底路径不显眼 |
| AI 对话 | 第 2 轮起自动关「附带原文」，用户不知上下文变摘要 |
| 族谱整理 | `alert` 与 toast 混用；0 写入时不知哪条关系姓名对不上 |
| 应用方案 | 两个快捷按钮与「应用方式」单选脱节 |
| 后端 | 重启后会话内存丢失；多进程导致 SQLite 锁 |
