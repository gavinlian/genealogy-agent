族谱软件界面PRD

本文档旨在定义基于浏览器的族谱管理系统的产品需求。系统定位于轻量级、高可用的家庭级数字家谱解决方案，兼顾专业研究者的需求，实现跨设备访问与协作。

产品概述

软件目标

开发一款基于浏览器的族谱管理系统，支持用户以可视化方式创建、编辑、浏览和分享家族成员关系图谱。系统定位于轻量级、高可用的家庭级数字家谱解决方案，兼顾专业研究者的需求，实现跨设备访问与协作。

用户群体

类型 描述 场景
家庭用户 普通个人或家庭成员 记录直系亲属三代以上信息
家谱爱好者 热衷于寻根问祖的非专业人士 收集五服以内家族成员资料
学术研究人员 历史学、人类学、社会学学者 构建大规模家族网络模型
文化机构 博物馆、地方志办公室 数字化保存传统族谱文献

核心价值

  • 可视化强：提供动态可交互的树状图展示，支持缩放和平移操作。
  • 易用性高：表单驱动的数据录入方式降低使用门槛。
  • 数据安全：支持本地加密备份与云端同步双重保障。
  • 格式兼容：原生支持主流族谱数据交换格式（如GEDCOM）。

功能需求列表

添加/编辑人物功能

Core Feature
输入与验证
  • 表单字段：姓名(必填)、性别、出生/死亡日期、出生地、职业、简介。
  • 验证：姓名1-50字符；出生日期≤当前日期；死亡日期≥出生日期。
保存逻辑

点击“保存”后触发AJAX请求，POST至 /api/person；若为编辑模式，则PUT至 /api/person/{id}。

关系管理功能

Logic
规则与验证
  • 类型：父子、母子、夫妻、兄弟姐妹（需指定长幼）。
  • 验证：不允许循环依赖（A是B的父亲，B不能是A的父亲）；夫妻关系双向对称。
  • 删除：弹出确认框，删除成功后自动重绘树状图。
关系验证伪代码
JavaScript (Validation)
function validateRelationship(personA, personB, type) { // Rule 1: No self-reference if (personA.id === personB.id) { return { valid: false, msg: "不能建立自我关系" }; } // Rule 2: Check for Cycles (Simplified DFS) if (hasPath(personB, personA)) { return { valid: false, msg: "禁止循环依赖" }; } // Rule 3: Age difference check for Parent-Child if (type.includes('Parent')) { const ageDiff = personA.birthYear - personB.birthYear; if (ageDiff < 12) { logWarning("父母与子女年龄差过小"); } } return { valid: true }; }

树状图展示功能

展示方式

D3.js力导向图或层级树布局，默认展开三代。

交互操作
  • 单击：显示详情
  • 双击：聚焦放大
  • 右键：快捷菜单
缩放控制

鼠标滚轮±10%，工具栏整倍数缩放。范围：25% - 200%。

搜索功能

支持姓名、出生地、职业、简介的模糊匹配。

前端: fuzzysort.js | 后端: Elasticsearch

导出功能

支持GEDCOM, JSON, PNG/SVG格式。

命名: {family_name}_genealogy_{timestamp}.{ext}

导入功能

支持GEDCOM (v5.5.1+) 和 JSON。自动处理ID冲突（追加后缀）。

备份与恢复

自动备份LocalStorage（最近5次），手动备份生成.zip。恢复需二次确认。

字段排列

  2. 性别（单选：男/女/其他）
  3. 出生/死亡日期（日期选择器）

  • 成功：按钮显示“✓ 保存成功”，2秒后关闭。

操作流程说明

添加新成员完整流程

1

用户点击顶部工具栏“新增人物”按钮。

2

弹出模态窗“添加人物”，初始表单为空。

3

用户依次填写姓名、性别等字段。

4

若必填项未填，点击“保存”时前端拦截并高亮提示。

5

填写完整后点击“保存”，发送POST请求至服务器。

6

接口返回成功状态码（201 Created）及人物ID。

7

前端关闭表单，在左侧树状导航区新增节点，并在图区添加对应圆圈节点，状态栏提示“✅ 新成员【XXX】已添加”。

建立关系流程

步骤 1-2: 分别选择两个人物A和B，点击“建立关系”。
步骤 3: 弹出配置对话框，选择类型（父子/夫妻/兄弟姐妹）。
步骤 4-5: 系统验证合法性，通过后插入记录并绘制连接线。
步骤 6: 提示“🔗 A 与 B 的关系已建立”。

搜索与导出流程

搜索： 输入关键词 -> 实时下拉显示匹配项（含关系路径） -> 点击结果 -> 图区平移缩放至该节点并高亮闪烁 -> 右侧加载详情。
导出： 点击“导出” -> 选择格式（GEDCOM/JSON/PNG） -> 系统生成文件并触发下载 -> 文件名按规则自动生成 -> 状态栏提示“💾 文件已开始下载”。
